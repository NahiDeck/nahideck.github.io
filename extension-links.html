NahiDeck Connect browser extension

Control the media tabs in your browser (YouTube, Spotify web) from your phone. Choose the store link for your browser.

Chromium-based browsers

Google Chrome, Microsoft Edge, Opera, Brave, Vivaldi and Yandex Browser install from the same store.

Important notes

  • You can install the extension separately in each browser you use.
  • Some Windows apps use Microsoft Edge by default, so we recommend installing the extension in Edge too.
  • If you use YouTube Music, you need to install the extension in Google Chrome.
  • After installing, confirm "Add extension" in the browser.
